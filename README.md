# SimplePOS

SimplePOS is a four-page Point-of-Sale foundation created using
CodeIgniter 4. This project demonstrates routes, controllers, views,
navigation, static PHP arrays, and foreach loops.

## Pages

- Home: `/`
- About: `/about`
- Customer Accounts: `/customers`
- User Accounts: `/users`

## Features

- Four working CodeIgniter routes
- Separate controllers and views
- Five sample customer records
- Five sample user or staff records
- Static PHP arrays used as temporary data sources
- Foreach loops used to display account records
- Shared navigation between all pages
- Responsive CSS design
- No database is used in this version
